# 介面與體驗規範 (UI/UX.md)：全國大學生二手物品交換與買賣平台

本文件旨在規範「全國大學生二手物品交換與買賣平台」之使用者介面 (UI) 與使用者體驗 (UX) 設計原則，確保行動優先 (Mobile-First) 的操作流暢度與校園社群的信任感。

---

## 一、 導覽架構 (Navigation Structure)

本平台採用行動版優先的底部導覽列 (Bottom Navigation Bar) 架構，讓學生在手機操作時能快速切換核心功能：

1. **首頁 (Home)**：推薦商品、熱門分類、最新上架、鄰近學校商品快覽。
2. **搜尋/探索 (Search & Explore)**：關鍵字搜尋、進階篩選（價格、學校、新舊程度、交易方式）。
3. **發布 (Post)**：一鍵快速上架閒置物品（結合拍照與資訊填寫）。
4. **訊息/通知 (Messages & Notifications)**：公開問答、買賣雙方私訊、系統與交易狀態通知。
5. **個人中心 (Profile)**：個人檔案、我的商品管理、收藏清單、歷史交易紀錄。

---

## 二、 主要畫面設計 (Main Screens)

1. **商品卡片列表頁**
   * **版面**：雙欄式格狀卡片 (Grid View)，兼顧螢幕資訊密度與圖片清晰度。
   * **卡片元素**：商品縮圖、標籤（出售/交換/贈送）、價格（或「NT$0 / 交換」）、商品名稱、所屬學校與距離標示。
2. **商品詳細頁**
   * **版面**：上方為多圖輪播橫幅 (Carousel)，下方為價格、標題、新舊狀態、交易方式與賣家資訊區塊。
   * **互動按鈕**：底部固定操作列，包含「加入收藏」、「公開提問」、「聯絡賣家 / 提出申請」。
3. **商品上架表單**
   * **版面**：單頁表單填寫，分段清楚（照片上傳、基本資料、價格與交易方式、校園面交地點）。
4. **會員中心與賣場**
   * **版面**：個人頭像、暱稱、校園身分驗證徽章、評分，下方分頁切換「上架中」、「預約中」、「已售出」商品。

---

## 三、 核心使用流程 (User Flows)

1. **買家瀏覽與購買/交換流程**
   * 開啟平台 $\rightarrow$ 瀏覽首頁或依學校/分類篩選 $\rightarrow$ 點擊商品查看詳情 $\rightarrow$ 登入帳號（若未登入） $\rightarrow$ 點擊「提出購買/交換申請」 $\rightarrow$ 確認面交地點與條件 $\rightarrow$ 雙方確認後進入交易完成並留下評價。
2. **賣家上架流程**
   * 點擊底部「發布」 $\rightarrow$ 上傳 1-5 張商品照片 $\rightarrow$ 填寫商品標題、分類、新舊程度、價格與交換意願 $\rightarrow$ 選擇交易方式（同校面交/寄送） $\rightarrow$ 提交上架。

## 四、 字體與色彩規範 (Typography & Color Guidelines)

1. **色彩系統 (Color Palette)**
   * **主色 (Primary)**：校園青綠色 `#10B981` (Tailwind Emerald-500) —— 象徵永續、環保與信任。
   * **輔助色 (Secondary)**：活力橘色 `#F59E0B` (Tailwind Amber-500) —— 用於標示「交換」或提醒狀態。
   * **背景色 (Background)**：淺灰白 `#F9FAFB` (Tailwind Gray-500) —— 提升閱讀舒適度。
   * **文字色 (Text)**：深灰 `#1F2937` (Tailwind Gray-800) 確保高對比易讀性。
2. **字體規範 (Typography)**
   * **字型家族**：`Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Microsoft JhengHei"`, `sans-serif`。
   * **階層大小**：
     * 頁面主標題 (H1)：`24px / Bold`
     * 區塊標題 (H2)：`18px / Semibold`
     * 正文/卡片標題：`14px / Regular` 或 `Medium`
     * 輔助說明/標籤：`12px / Regular`

---

## 五、 特殊狀態處理 (Empty, Loading, and Error States)

1. **空白狀態 (Empty States)**
   * **無搜尋結果**：「找不到相關商品，試試看其他關鍵字或調整篩選條件？」並附帶「清除篩選」按鈕與推薦熱門商品。
   * **無收藏/無訊息**：「目前還沒有收藏任何商品，快去逛逛尋寶吧！」搭配引導按鈕。
2. **載入中狀態 (Loading States)**
   * **圖片與列表載入**：採用骨架屏 (Skeleton Screen) 動態灰色塊，避免畫面跳動，提升體感流暢度。
   * **表單提交中**：按鈕轉為 Spinner 狀態並呈現「上架中...」，避免重複點擊。
3. **錯誤狀態 (Error States)**
   * **網路異常 / 伺服器錯誤**：顯示友善提示圖示與「重新整理」按鈕。
   * **表單驗證錯誤**：必填欄位下方以紅字顯示提示（例如：「請上傳至少一張商品照片」、「價格不能為負數」）。
